# Evaluation assets

This directory contains the reproducible synthetic rule-level evaluation for TriageBloom.

- `labelled_cases.json` contains synthetic cases and expected rule IDs.
- `results-v0.2.0.json` is generated by `python scripts/evaluate_labelled.py` during release preparation.

The cases are software-verification fixtures. They are not a substitute for independent or production validation. See `docs/EVALUATION.md`.
